# EM Visions — site vitrine

Site bilingue (FR/EN) de l'atelier d'impression EM Visions (Saint-Léonard, Montréal).

**Cette branche (`version-2`) contient la deuxième version du site** : même logo, mêmes couleurs, mêmes images et vidéos, mais une mise en page simple et lisible, pensée pour une clientèle peu à l'aise avec Internet. La première version (design « papier déchiré ») est conservée telle quelle dans la branche `version-1-papier-dechire`.

## Contenu
| Dossier | Description |
| --- | --- |
| `docs/00-SPECIFICATION-INITIALE.md` | Spécification UX/UI et full stack d'origine |
| `docs/` | Les 6 documents « avant de coder » : PRD, TRD, App Flow, UI/UX, Backend Schema, Implementation Plan |

## Fonctionnalités
Page unique défilante · en-tête fixe avec bouton « Demander un devis » · français à `site/`, anglais à `site/en/` · thème clair (par défaut) et sombre · ordinateur, tablette et cellulaire · 15 réalisations avec fiche par projet · catalogue de 24 produits par catégorie, relié au modélisateur 3D · formulaire de devis en trois étapes · prix sur demande.

Les documents de `docs/` décrivent la première version ; ils restent ici comme référence.

## Utiliser les documents avec un outil de code IA
Donner les 6 fichiers de `docs/` ensemble, demander de signaler les contradictions, les résoudre, puis suivre `06-IMPLEMENTATION-PLAN.md`.
